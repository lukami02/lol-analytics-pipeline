# League of Legends Analytics Pipeline

An end-to-end data engineering project that collects League of Legends match data from the Riot Games API and prepares it for analytical processing.

## Tech Stack

- Python
- Riot Games API
- Google BigQuery
- dbt
- Apache Airflow
- FastAPI
- Docker

## Project Status

Currently in development. The initial phase focuses on Riot API integration and match data extraction.

## Planned Data Flow

Riot Games API → Python Extraction → BigQuery → dbt → FastAPI

Apache Airflow will orchestrate the pipeline.
